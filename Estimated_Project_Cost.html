Estimated Infrastructure Scaling Cost

Project: Exam Bank (Phase 2 Commercial Scale-Up)

Prepared By: Engineering Team
Date: September 17, 2026
Client: Mr. Voice
Target Capacity: 500+ Concurrent Students

Phase 1 (Prototyping) of the Exam Bank system is built using free developer tools at zero infrastructure cost. This document outlines the estimated budget required to upgrade the system to Phase 2: a commercial-grade environment capable of handling 500 students taking exams simultaneously without performance issues.

Infrastructure Item Description Estimated Cost (₦)
1. Dedicated PostgreSQL Database Migration from local SQLite to a persistent, managed PostgreSQL instance for long-term data storage. ₦50,000
2. In-Memory Redis Caching High-speed Redis cluster to store active exam sessions, randomized questions, and answers in memory, ensuring zero lag for students. ₦15,000
3. Backend Server Upgrade "Always-on" serverless infrastructure with increased RAM and CPU to process simultaneous exam submissions instantly. ₦45,000
4. Frontend Pro Hosting & CDN Premium global hosting (e.g., Vercel Pro) to ensure the UI loads quickly for hundreds of students at the same time. ₦45,000
5. Cloud Image & Asset Storage Premium cloud storage (AWS S3 / Cloudinary) and bandwidth for hosting imported question images reliably. ₦20,000
6. Domain Name & SSL Security Registration of a custom premium domain name (e.g., .com or .edu.ng) and advanced SSL security certificates. ₦15,000
7. Load Testing & Performance Tuning Simulated load testing of 500 concurrent users to identify and fix bottlenecks before commercial launch. ₦30,000
8. Miscellaneous / Contingency Buffer for unexpected bandwidth spikes or minor infrastructure adjustments during the scaling phase. ₦20,000
Total Phase 2 Scaling Budget (1 Year Est.): ₦240,000

*Note: This budget is designed specifically for the Phase 2 upgrade to support 500 simultaneous users. The Phase 1 prototype build remains at ₦0 infrastructure cost.
